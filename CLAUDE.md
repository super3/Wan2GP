# Instructions for Claude

## This repo is a fork

This is **super3/Wan2GP** (https://github.com/super3/Wan2GP), a fork of the
upstream WanGP project.

- Link and name only the fork. Our pull requests, issues, branches and commits
  are `https://github.com/super3/Wan2GP/pull/<number>` and so on.
- Don't name or link the upstream repository in messages, PR descriptions or
  instructions, not even as a warning ("not the upstream one"): the user's app
  turns `owner/repo` into a link. Mention upstream only when the user asks about
  upstream itself, and then say plainly that it is upstream.
- Open pull requests against the fork's `main`, never against upstream.
