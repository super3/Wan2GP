# Endless TV content sources

The sources behind the Endless TV channels' clips: scripts, prompts, the code that draws the cartoons, and the exact key frames the GPU boxes rendered from. The rendered videos live on the Endless TV app (Railway volume), not here.

## news/

`riverside_tonight_2026-11-25_script.md` is a 10-minute Riverside Tonight script on five of the day's top stories. It's a draft for review, not yet rendered. It is split into 40 clips of 15 seconds, each read by the anchor on the channel's first frame, and has sources and review notes at the end.

## laugh-track/

`comic_sets.py` holds the stand-up sets: each comic's look and eight 15-second bits. Each bit is rendered as one clip that starts and ends on the comic's still, and `tools/make_set.py` joins a comic's eight clips into a 2-minute set.

## doodle/

Five original 2-minute cartoon shorts, one per 90s-TV-inspired style. The characters, stories, settings and music are all original.

| Folder | Short | Status |
|---|---|---|
| `retro_exaggerated` | Bertram Bigsby in *The Littlest Crossing* | Rendered, on Doodle |
| `bold_shapes` | *Squeaky Doyle: One Little Smudge* | Rendering |
| `desert_chase` | Pip the Armadillo in *Clean Sweep* | Rendering |
| `geometric_lab` | Mr. Hoist in *One Small Passenger* | Key frames ready, not rendered yet |
| `wobble_suburb` | *Wendell in: One Lousy Dandelion* | Key frames ready, not rendered yet |

Each folder has:

- **`script.md`**: the script (logline, beats, dialogue).
- **`shots.json`**: the shot list: each shot's H3 prompt, length in frames, and its start and end key frames.
- **`keys/`**: the key frames, exactly as the GPU boxes received them (1280x704, JPEG quality 93, 4:4:4).
- **`code/`**:
  - The drawing code that makes the key frames, plus the title and end cards and the synthesised music bed.
  - `assemble.py RENDERS_DIR OUT.mp4`, which joins the rendered shots (named `s01.mp4`, `s02.mp4`, …) with the cards and the music.
- **`style/`**: the style study: notes, the H3 prompt and the key art.

Left out because of size, and regenerated by the code: the music beds (WAV), the title and end cards, and the animatics.

## tools/

| File | What it does |
|---|---|
| `pack_all.py` | Packs every short's key frames into runs on the Endless TV app, plus one render command per GPU box. Run ids must be lowercase, and the boxes see only the latest 50 runs, so everything for every box has to fit in one batch. |
| `shorts_box.py` | The GPU box script. It renders each shot from its start key frame to its end key frame on MiniMax H3 FL2VA 33B, using the Larry v4 4-step profile with Audio Refinement, at 1280x704. |
| `post_short.py` | The older one-short-at-a-time version of `pack_all.py`. |
| `make_set.py` | Joins clips that start and end on the same still into one set, dropping the duplicate frame at each join. |

The scripts use the paths of the session that made them (a scratchpad folder and `outputs/shorts/<slug>`). Adjust those before reusing them.
